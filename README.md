# Telegram Media Downloader Bot

This bot lets you download TikTok and Instagram  videos and Spotify tracks/albums/playlists (as MP3) directly from Telegram.

## ✅ Features
- Download TikTok & Instagram videos
- Download Spotify songs, albums, playlists in MP3
- No watermark, no ads

## 🚀 How to use
1. Clone this repo
2. Install requirements: `pip install -r requirements.txt`
3. Add your API keys 
4. Run with `python`

## 🔧 Tools used
- Python 3
- spotipy
- yt-dlp
- python-telegram-bot
